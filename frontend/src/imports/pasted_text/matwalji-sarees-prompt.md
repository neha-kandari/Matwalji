# Figma Make Prompt

## Project Overview

Design a premium luxury e-commerce website for an Indian ethnic fashion brand named **MATWALJI Sarees**.

The website specializes in **Luxury Sarees, Bridal Lehengas, Designer Wear, and Festive Collections.**

This is **not a traditional e-commerce website.**

There is **no payment gateway**.

Instead, customers browse products, save their favorite items to a **Wishlist**, and submit an enquiry. The wishlist is then sent directly to the business owner through the admin panel and email.

The overall aesthetic should feel premium, elegant, timeless, and luxurious—similar to **Sabyasachi, Aza Fashions, Pernia's Pop-Up Shop, Torani, and Raw Mango**, but with a unique identity.

Create a visually stunning luxury fashion website that feels like an editorial boutique rather than a standard online store. Every screen should emphasize elegance, craftsmanship, and exclusivity. The admin experience should be clean, efficient, and suitable for managing products, collections, banners, and customer enquiries.
